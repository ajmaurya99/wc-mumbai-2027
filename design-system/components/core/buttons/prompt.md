# Prompt: buttons

A WordPress core Buttons block, centred, holding one primary button (Fill
style, no per-block colours so Styles → Blocks → Button applies: Accent 1
`#0073aa` background, white text, 999px radius, `.6rem 1.5rem` padding, 700
weight, 16px) and optionally one secondary button (Outline style with text
colour preset `accent-1`, which also colours its 2px border). Labels are short
verbs with real hrefs. Hover: primary turns Accent 3 `#6d28d9`, outline fills
Accent 1 with white text; focus ring 2px `#6d28d9` offset 3px; 200ms
transitions with a prefers-reduced-motion guard. Never two primaries in one
section.
