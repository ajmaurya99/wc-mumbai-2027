# Prompt: section header

A section header for WordCamp Mumbai 2027 built from core blocks: a Group
(flow layout, blockGap preset 20) containing an eyebrow Paragraph (font size
preset small, weight 700, uppercase, letter-spacing 0.08em, text colour preset
accent-2), an H2 Heading (font size preset x-large, Contrast, inheriting
Newsreader 700 from Styles) and an optional one-line tagline Paragraph in the
Kalam font preset, size large, colour accent-2. Centre-aligned for symmetric
sections, left-aligned in two-column sections. No CSS.
