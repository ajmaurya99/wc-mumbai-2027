# Prompt: sponsor tier grid

A sponsors-by-tier grid for WordCamp Mumbai 2027: a core Group with wide
alignment, constrained layout and blockGap preset 40. For each tier, a
centred eyebrow Paragraph (size preset small, weight 700, uppercase, letter
spacing 0.08em, text colour preset accent-2) followed by a Columns block with
wide alignment, blockGap preset 30 and three Columns, each holding an Image
block with aspect ratio 3:2, scale contain, a custom link to the sponsor with
rel sponsored, and alt text equal to the sponsor's name. Equal-height boxes,
no distortion, no CSS. Logos are PNG or WebP at 2×.
