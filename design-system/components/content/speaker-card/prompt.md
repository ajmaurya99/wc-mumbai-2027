# Prompt: speaker card

A speakers grid for WordCamp Mumbai 2027: a core Columns block, alignment
wide, blockGap preset 30, stacked on mobile, three Columns. Each holds a Group
with class wcm-card, radius 16px, padding preset 40, background preset
accent-5, flow layout with blockGap preset 20. Inside: a square Image (aspect
ratio 1, scale cover, radius 16px, alt text is the speaker's name), an H3
Heading at size preset large with the name, and a Paragraph at size preset
small in text colour preset accent-4 with the role and company. Hover shadow
and lift come from the shared `card.css`. No social icons, no custom values.
