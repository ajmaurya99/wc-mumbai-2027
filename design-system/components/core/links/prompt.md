# Prompt: links

Text links for WordCamp Mumbai 2027 body copy: plain anchors inside core
Paragraph blocks, no wrapper or classes. Rest state Contrast `#0d1b2a` with no
underline; hover shows an underline coloured Accent 1 `#0073aa`; keyboard focus
draws a 2px `#6d28d9` ring offset 3px; 200ms transition guarded by
prefers-reduced-motion. A standalone call-to-action link is its own paragraph
with descriptive text. CSS lives in `links.css`, scoped to `.entry-content`
and excluding `.wp-element-button`.
