# Prompt: separator

An ornamental section separator for WordCamp Mumbai 2027: a core Group with
class wcm-sep, flex layout, no wrap, justified centre, wide alignment, blockGap
preset 30, padding preset 40 top and bottom. Inside: a Separator block with
background preset accent-2 and class wcm-sep__line, an Image block 200px wide
showing the diamond-icon-diamond PNG (marigold, local train, vada pav, cutting
chai, taxi or Gateway of India), and a second Separator. CSS turns each
Separator into a flexible dashed 2px `#006b78` line.
