# Prompt: FAQ details

An FAQ list for WordCamp Mumbai 2027 built from core Details blocks inside a
Group (flow layout, blockGap preset 30). Each Details block has the class
wcm-faq, background preset accent-5, border radius 16px and padding preset 40
on all sides; its summary is the question and its content one or two short
Paragraphs. No JavaScript: the native details element does the expanding.
`faq-details.css` makes the summary bold, colours the marker Accent 1
`#0073aa`, spaces the open answer with spacing preset 30 and adds the
`#6d28d9` focus ring.
